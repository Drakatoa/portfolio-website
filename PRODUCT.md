## Platform

web

## Product purpose

Rajit Goel's personal portfolio presents games, AI engineering, and interaction/design work. Visitors can explore projects, follow demo/code/case-study links, read about Rajit, and open the CV.

## Users

Peers, collaborators, and recruiters. The relative priority remains open; the landing-page proposal keeps project and CV access direct for all three.

## Capabilities and constraints

Next.js App Router with React and TypeScript. Existing case-study routes and project links remain functional. The user has authorized a landing-page implementation for review before changes extend to the rest of the site. Nothing is deployed as part of this pass.

## Brand commitments

Preserve the original black-and-white identity, sharp 14-degree parallelogram frames, oversized italic lettering and Persona 3-like menu selection geometry. The user rejected the muted editorial redesign; preserve the approved casual bio while correcting the visuals. Dark and edgy, with a more abstract anime portrait inspired by the simplicity of Daniel Pu's avatar and some Persona-like graphic character. Casual, dry writing informed by near.blog and the user's LinkedIn drafting history, but longer and distinct from the LinkedIn bio. Preserve a featured project carousel; replace repetitive project cards with a readable index.

## Evidence on hand

Existing project images, links and case studies; the supplied current CV at `public/rajit-goel-cv.pdf`; three user-supplied reference photographs in the conversation; public LinkedIn content; the user's pasted writing iterations. The generated portrait is a static concept. No layered source art or Cubism rig is available yet.

## Latest accepted constraints

Original carousel design and animations are the baseline: retain ProjectSlide primary action, offset media frame, dots, counter and controls. Keep content less boxed. Name below portrait, no oversized name in left hero. Open linked About accomplishments grounded in CV. Persona3 highlight is overlapping white/pink triangular wedges crossing the label, never cursor arrows or cyan border glows. Restore original four-point sparkle, Fun Stuff nav, games and albums; records slide from sleeves on hover/focus.
